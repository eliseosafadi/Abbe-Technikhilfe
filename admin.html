Texte bearbeiten

Hier können Sie jeden Text der Startseite ändern. Ihre Eingaben werden automatisch in diesem Browser gespeichert — online geht die Änderung erst, wenn Sie die neue Datei bei GitHub hochladen.

So veröffentlichen Sie Ihre Änderungen:
  1. Texte unten ändern und mit „Vorschau“ prüfen.
  2. „Neue index.html herunterladen“ anklicken.
  3. Diesen GitHub-Link öffnen, die heruntergeladene Datei in das Fenster ziehen und auf „Commit changes“ klicken.

Die alte Startseite wird dabei ersetzt; nach ein bis zwei Minuten ist die Änderung online. Fettdruck: **so markierte Wörter** erscheinen fett.
