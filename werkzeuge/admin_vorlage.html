Zugangsschlüssel für GitHub

Damit diese Seite Ihre Änderungen direkt veröffentlichen kann, braucht sie einmalig einen Zugangsschlüssel von GitHub. Er wird nur in diesem Browser gespeichert und darf nur die Dateien dieser einen Webseite ändern.

  1. Diesen Link öffnen (Sie müssen bei GitHub angemeldet sein).
  2. Bei „Token name“ z. B. Admin-Seite eintragen. Bei „Expiration“ No expiration wählen (falls nicht angeboten: „Custom“ und ein Datum weit in der Zukunft).
  3. Bei „Repository access“ Only select repositories wählen und Abbe-Technikhilfe auswählen.
  4. Bei „Permissions“ auf „Repository permissions“ tippen und dort Contents auf Read and write stellen.
